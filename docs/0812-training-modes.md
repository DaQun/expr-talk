# 训练模式盘点与扩展建议

> 日期：2026-08-12  
> 范围：ExprTalk 现有训练模式能力地图、缺口分析、可新增方式与落地优先级  
> 依据：`packages/shared/src/mode.ts`、`README.md`、`docs/0805.md`、`docs/0805-requirements.md`、`docs/architecture.md`

---

## 1. 现在有什么

| 模式 | 形态 | 主要练什么 | 技术复用 |
|------|------|------------|----------|
| **自由发挥** `free` | 单轮 | 开口、结构、少废话 | 录音 → 转写 → 报告 |
| **口播 · 按主题** `short_video` | 单轮 + 题库 | 钩子、密度、节奏、记忆点 | 同上 + 主题题库 |
| **辩论** `debate` | 多轮交互 | 立论、论据、预判反驳 | 反方质询 workbench |
| **费曼学习法** `feynman` | 多轮交互 | 讲清概念、少术语、因果与例子 | 小白追问 workbench |

### 1.1 模式元数据（代码现状）

| 模式 | 默认目标 | 建议时长 | 评分侧重（摘要） |
|------|----------|----------|------------------|
| free | 结构更清晰 | 90s | 逻辑 30% · 结构 25% · 清晰 20% · 直接 15% · 密度 10% |
| short_video | 提高信息密度 | 60s | 钩子 25% · 逻辑 20% · 密度 20% · 节奏 20% · 记忆点 15% |
| debate | 先说结论 | 90s | 逻辑 35% · 说服 25% · 结构 20% · 直接 10% · 清晰 10% |
| feynman | 结构更清晰 | 120s | 清晰 35% · 结构 25% · 逻辑 20% · 密度 10% · 直接 10% |

### 1.2 历史 mode（已合并）

类型里仍保留旧 id 映射，现统一归一到 `free`：

| 旧 mode | 原意（推断） | 现状 |
|---------|--------------|------|
| `impromptu` | 即兴发言 | → free |
| `meeting` | 会议发言 | → free |
| `interview` | 面试 | → free |
| `presentation` | 汇报 / 演讲 | → free |
| `retelling` | 复述转达 | → free |
| `emotion_expression` | 情感表达 | → free |

说明：产品早期就想覆盖**职场场景**和**情感表达**，后来收成 4 个核心模式。旧会话数据通过 `normalizePracticeMode` 兼容。

### 1.3 练习页提示（用户可见）

- **free**：题目可自拟。先开口、有结构即可；卡壳用静默，别用填充词拖时间。
- **short_video**：前 3 秒必须有钩子；一句一个点；结尾要有行动号召。建议 45–60 秒。
- **debate**：先一句亮明立场，再给两条可检验论据，最后主动回应一个反方点。建议 90 秒立论。
- **feynman**：把概念讲给小白听：少术语，说清因果，给一个例子。小白会一直追问，直到能理解为止。

## 2. 能力地图：覆盖与缺口

### 2.1 当前覆盖较满

- 结构 / 逻辑 / 说服
- 讲解清晰（费曼）
- 短内容节奏与钩子（口播）
- 对抗性质询与论据（辩论）

### 2.2 明显缺口

| 缺口 | 说明 |
|------|------|
| **即兴反应** | 限时、抽题、打断、追问压力 |
| **职场场景话术** | 汇报 / 面试 / 会议插话 |
| **倾听后复述与转达** | 听懂 → 用自己的话压缩转达 |
| **情绪与语气** | 安抚、冲突、共情 |
| **叙事与故事** | 经历讲述，非观点辩论 |
| **听众适配** | 对老板 / 客户 / 新人讲同一件事 |

```
当前覆盖较满：结构 / 逻辑 / 说服 / 讲解清晰 / 短内容节奏
明显缺口：
  · 即兴反应（限时、打断、追问）
  · 职场场景话术（汇报 / 面试 / 会议）
  · 倾听后复述与转达
  · 情绪与语气（安抚、冲突、共情）
  · 叙事与故事（经历讲述，非观点辩论）
  · 听众适配（对老板 / 对客户 / 对新人讲同一件事）
```

## 3. 建议可增加的方式（按优先级）

### 3.1 P0 — 强相关、架构好接、价值高

| 新模式 | 练什么 | 建议形态 | 为何优先 |
|--------|--------|----------|----------|
| **即兴发言** `impromptu` | 抽题限时、先结论后展开 | 单轮 + 倒计时题库 | 老 id 已在，和 free 差在「抽题 + 限时压力」 |
| **面试模拟** `interview` | STAR、行为题、追问补洞 | 多轮（复用辩论/费曼交互壳） | 高频刚需，质询逻辑可复用 |
| **工作汇报** `presentation` | 结论先行、数据/进展/风险/求助 | 单轮或 1 次追问 | 职场最常见，评分可重结构 + 可执行 |
| **复述转达** `retelling` | 听一段 → 用自己的话讲清 | 单轮（材料 → 用户讲） | 练倾听与信息压缩，和费曼互补 |

### 3.2 P1 — 有差异化，稍复杂

| 新模式 | 练什么 | 建议形态 |
|--------|--------|----------|
| **会议发言** `meeting` | 30–60 秒插话：对齐、异议、收口 | 单轮情景题 |
| **异议处理** `pushback` | 被质疑后冷静回应 | 多轮（轻量辩论，偏职场语气） |
| **受众改写** `audience_shift` | 同一观点对 3 类人各讲一遍 | 单轮连录 3 段，或分段复练 |
| **故事讲述** `story` | 经历叙事：冲突–转折–收获 | 单轮，评分偏记忆点 / 节奏 |

### 3.3 P2 — 可做，但依赖能力或后置

| 新模式 | 说明 |
|--------|------|
| **情感表达** `emotion_expression` | 架构文档提过 SenseVoice 情感；需 ASR / 韵律能力更成熟再做主打 |
| **电梯演讲** `elevator_pitch` | 30 秒产品 / 自己介绍，可视为口播子类型，不必独立模式 |
| **双语 / 英语表达** | 扩人群，但 ASR / LLM / 评分都要另建一套 |

## 4. 不一定要「加模式」的增强（往往更划算）

产品文档（`docs/0805.md`、`docs/0805-requirements.md`）的方向是：**先别再堆模式入口，把现有 4 个练深**。

| 增强 | 说明 | 与现有模式关系 |
|------|------|----------------|
| **今日推荐** | 根据画像短板 → 自动选模式 + 题目（首页一键开始） | 不新增 mode |
| **微课形态** | 例如「只练钩子 3 遍」「只练先说结论」 | 仍是 free / 口播，换训练目标与题库 |
| **情景皮肤** | 「对老板汇报」「客户异议」等题目与 rubric 包装 | 同一套 free / 辩论，先不当新 mode |
| **测评基线** | 首次 3 分钟表达测评 → 生成计划 | 比第 5 个模式更影响留存 |

原则：

> 新模式必须带来**不同交互或不同评分重点**；若只是换题目，用题库 + 目标（`TrainingGoal`）即可，避免首页再多几个 Card。

## 5. 落地建议（务实路线）

### 近期（不扩 mode 枚举）

- 口播 / 自由：补「面试 / 汇报 / 会议」题库与评分提示
- 辩论：加「职场异议」题包
- 首页：AI 推荐今日练什么（见 S2 需求）

### 中期（1–2 个新 mode）

- `interview`（多轮，复用交互 workbench）
- `impromptu` 或 `presentation`（单轮，复用 free 流水线）

### 后期

- `retelling`（需材料输入：粘贴 / 读稿 / 短音频）
- `emotion` / 韵律类

### 推荐实现顺序（若正式加 mode）

```
1. interview     — 多轮，复用辩论/费曼交互壳 + 面试题库 + STAR 评分
2. impromptu     — 单轮，抽题 + 限时 UI + 偏「先结论」rubric
3. presentation  — 单轮情景 + 可执行性维度
4. retelling     — 依赖材料输入管线后再做
```

## 7. 小结

- **现在 4 个模式已经覆盖**：开口基础、内容传播、对抗说服、讲解清晰——骨架是够的。
- **最大空白在场景化职场表达**：面试、汇报、会议、复述；以及**限时即兴**。
- **最值得加的两个真 mode**：`interview`（多轮追问）、`impromptu` 或 `presentation`（单轮情景）。
- **更优先的产品动作**：今日推荐 + 测评闭环 + 用题库包装场景，而不是一口气加 5 个模式。
