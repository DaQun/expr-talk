# @showtalk/desktop

Tauri 2 + React 桌面端。

## 开发

在仓库根目录：

```bash
npm install
npm run dev          # 仅 Vite 前端
npm run tauri:dev    # 桌面壳
```

## 当前能力

- 信息架构页面：Home / Practice / Review / Retry / History / Profile / Settings
- 粘贴逐字稿 → core 指标 → 规则报告 → 复练入口
- Rust command 占位：session / asr / llm / history
